BIRTHDAY SURPRISE WEBSITE

Files:
- index.html: the website homepage (correct filename for GitHub Pages)
- assets/: six image files used by the photo gallery

Publish with GitHub Pages:
1. Open your GitHub repository.
2. Upload index.html and the entire assets folder to the repository root.
3. Keep the branch set to main.
4. Open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait a few minutes and open:
   https://heyone-prog.github.io/birthday-surprise/

Important: Upload the assets folder too, or the gallery images will not appear.
